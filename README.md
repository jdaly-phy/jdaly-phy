## What I'm working on

### [RVV-LAB](https://github.com/jdaly-phy/rvv-lab)
A hands-on laboratory for the **RISC-V Vector extension (RVV 1.0)**.

- Writing hand-vectorized routines in RVV assembly and C/C++ intrinsics
- Benchmarking vector vs. scalar performance (`vlen` sensitivity, `vlmax`, tail handling patterns)
- Comparing auto-vectorization output from GCC/Clang against handwritten kernels
- Documenting findings — usable snippets, pitfalls, and performance notes
